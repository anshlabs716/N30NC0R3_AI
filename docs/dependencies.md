# Dependencies

This page lists the main third-party components used by neoncore and what each
one is for. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for
attribution.

- **llama.cpp** — fetched and built during `make`
- **Ollama** — optional local LLM server
- **Pollinations** — default free, keyless cloud AI (an API key is optional)
- **GTK3** — desktop UI
- **libcurl** — networking
- **espeak-ng** — text-to-speech
